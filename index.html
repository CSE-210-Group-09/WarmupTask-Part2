CSV Plot

One dataset, two views.

CSV: a header row of column names, then one number per column on every row. XML: one <point> per row, with a field per column, such as <point x="1" y="3"/> or <point><x>1</x><y>3</y></point>. JSON: an array of objects with a number for each column, such as [{"x": 1, "y": 3}, {"x": 2, "y": 5}]. Excel (.xlsx): the first worksheet, read like a CSV, with column names in its first filled row. Importing replaces the current data.
